# CS4313 Software Engineering Project

A group project from the CS4313 Software Engineering module of the LM051
degree at the University of Limerick. It is a PHP auction website called
CharityBay.

## What it does

- User registration, login, profiles with avatars and a member list.
- Auction listings with image uploads, a countdown timer, search and an
  auction view page.
- A news page and an admin page.

## Tech

- PHP with a small custom framework in `system` (controller, views,
  modules, plugins, session and database managers)
- MySQL
- jQuery and jQuery UI, with templates in `views`

## Running

Serve the folder with PHP and a MySQL database, then set the database
details in `conf.php`.
